# โครงสร้างฐานข้อมูลตัวชี้วัด

เอกสารนี้อธิบายการออกแบบข้อมูลใน Google Sheet ซึ่งทำหน้าที่เป็นฐานข้อมูลหลัก ทุกตารางเชื่อมกันด้วยรหัสตามหลักสูตร จึงอ้างอิงข้ามตารางได้โดยไม่ต้องสร้างรหัสใหม่

## 1. ลำดับชั้นของข้อมูลตามหลักสูตร

```
กลุ่มสาระการเรียนรู้ (subject)        เช่น ค คณิตศาสตร์
 └ สาระ (strand)                      เช่น สาระที่ 1 จำนวนและพีชคณิต
    └ มาตรฐาน (standard)              เช่น ค 1.1
       └ ตัวชี้วัด (indicator)         เช่น ค 1.1 ป.4/2
            ประเภท: ระหว่างทาง หรือ ปลายทาง
            กลุ่มที่: ผูกตัวชี้วัดระหว่างทางเข้ากับตัวชี้วัดปลายทางที่เป็นเป้าหมายเดียวกัน
```

ข้อสังเกตจากเอกสารต้นฉบับ รหัสตัวชี้วัดบรรจุข้อมูลครบในตัว คือ อักษรกลุ่มสาระ เลขสาระ เลขมาตรฐาน ระดับชั้น และลำดับ ระบบจึงถอดชั้น มาตรฐาน และสาระจากรหัสโดยตรง ไม่พึ่งตำแหน่งในเอกสาร ซึ่งลดความคลาดเคลื่อนเมื่อหัวข้อในเอกสารไม่สม่ำเสมอ

## 2. ตารางในชีต

### 2.1 indicators (ตารางหลัก หนึ่งแถวต่อหนึ่งตัวชี้วัด)

| คอลัมน์ | ความหมาย | ตัวอย่าง |
| --- | --- | --- |
| code | รหัสมาตรฐานของระบบ ใช้เลขอารบิก เป็นคีย์หลัก | ค 1.1 ป.4/2 |
| code_th | รหัสเลขไทยสำหรับแสดงผลและพิมพ์เอกสาร | ค ๑.๑ ป.๔/๒ |
| subject_code | อักษรกลุ่มสาระ | ค |
| subject_name | ชื่อกลุ่มสาระ | คณิตศาสตร์ |
| strand_no | เลขสาระ ถอดจากรหัสมาตรฐาน | 1 |
| strand_name | ชื่อสาระ จากหัวข้อในเอกสาร | จำนวนและพีชคณิต |
| standard_code | รหัสมาตรฐาน เชื่อมกับตาราง standards | ค 1.1 |
| grade | ระดับชั้น | ป.4 |
| grade_order | ลำดับชั้นสำหรับเรียง ป.1 ถึง ป.6 คือ 1 ถึง 6 ม.1 ถึง ม.3 คือ 7 ถึง 9 ม.4-6 คือ 10 | 4 |
| seq | ลำดับตัวชี้วัดในมาตรฐานและชั้นนั้น | 2 |
| type | ระหว่างทาง หรือ ปลายทาง | ปลายทาง |
| group_no | กลุ่มที่ ตามตารางในเอกสาร | 1 |
| group_key | คีย์กลุ่ม รูปแบบ อักษรกลุ่มสาระ, ชั้น, สาระ, กลุ่มที่ คั่นด้วยเครื่องหมาย \| | ค\|ป.4\|1\|1 |
| text | ข้อความตัวชี้วัด | เปรียบเทียบและเรียงลำดับจำนวนนับ... |
| doc_order | ลำดับที่พบในเอกสาร ใช้ย้อนตรวจกับต้นฉบับ | 37 |
| source_file | ชื่อไฟล์ต้นฉบับ | 2. กลุ่มสาระการเรียนรู้คณิตศาสตร์ .docx |
| reviewed | ทำเครื่องหมาย TRUE เมื่อตรวจทานแล้ว แถวนี้จะไม่ถูกทับเมื่อนำเข้าใหม่ | TRUE |
| note | บันทึกของผู้ตรวจทาน | แก้ข้อความตามต้นฉบับ PDF |
| updated_at | เวลาที่นำเข้าหรือปรับปรุง | 2026-11-07 |

### 2.2 standards

| คอลัมน์ | ความหมาย |
| --- | --- |
| standard_code | รหัสมาตรฐาน เช่น ค 1.1 (คีย์หลัก) |
| standard_code_th | รหัสเลขไทย |
| subject_code | อักษรกลุ่มสาระ |
| strand_no | เลขสาระ |
| text | ข้อความมาตรฐาน |

### 2.3 strands

| คอลัมน์ | ความหมาย |
| --- | --- |
| strand_key | คีย์ เช่น ค\|1 |
| subject_code, strand_no, strand_name | กลุ่มสาระ เลขสาระ และชื่อสาระ |

### 2.4 subjects

subject_code, subject_name, subject_order, source_file, imported_at

### 2.5 summary_official

จำนวนตัวชี้วัดตามตารางสรุปหน้าแรกของแต่ละเอกสาร ได้แก่ subject_code, grade, grade_order, total, between, final ใช้เป็นเกณฑ์ตรวจความครบถ้วน

### 2.6 validation

เปรียบเทียบจำนวนที่ระบบแยกได้กับ summary_official รายกลุ่มสาระรายชั้น สถานะมี 3 ค่า คือ ตรงกัน ต้องตรวจสอบ และไม่มีในตารางสรุป

### 2.7 import_log

บันทึกการนำเข้าแต่ละไฟล์ จำนวนตัวชี้วัด และคำเตือนจากตัวแยกข้อมูล

## 3. ความสัมพันธ์ระหว่างตาราง

```
subjects.subject_code ─┬─ strands.subject_code
                       ├─ standards.subject_code
                       └─ indicators.subject_code
standards.standard_code ── indicators.standard_code
indicators.group_key    ── indicators.group_key   (ระหว่างทางหลายตัว สู่ปลายทางหนึ่งตัวหรือมากกว่า)
summary_official (subject_code, grade) ── validation (subject_code, grade)
```

## 4. หลักการกำหนดรหัส

1. คีย์หลักใช้รหัสตามหลักสูตรที่แปลงเป็นเลขอารบิก เว้นวรรคหนึ่งช่องระหว่างอักษร มาตรฐาน และชั้น เช่น ท 1.1 ป.1/3
2. เก็บรหัสเลขไทยคู่กันเพื่อใช้ในเอกสารราชการ
3. การค้นหาตัดช่องว่างและแปลงเลขไทยเป็นอารบิกก่อนเปรียบเทียบ ผู้ใช้จึงพิมพ์ ค1.1ป.4 หรือ ค ๑.๑ ป.๔ ก็พบผลเดียวกัน

## 5. ขั้นตอนการแยกข้อมูลจากเอกสาร

1. แปลงไฟล์ .docx เป็น Google Docs ชั่วคราว
2. อ่านเนื้อหาตามลำดับ ย่อหน้าหัวข้อชั้นและสาระใช้กำหนดบริบท ตารางสรุปใช้เก็บจำนวนทางการ ตาราง 3 คอลัมน์ใช้แยกตัวชี้วัด
3. แถวที่ขึ้นต้นด้วยคำว่า มาตรฐาน แยกเป็นข้อความมาตรฐาน กรณีหนึ่งเซลล์มีหลายมาตรฐานจะแบ่งตามคำว่า มาตรฐาน
4. ค้นรหัสตัวชี้วัดในเซลล์ด้วยรูปแบบ อักษร เลข.เลข ป.หรือม. เลข/เลข หนึ่งเซลล์อาจมีหลายรหัส ข้อความหลังรหัสถึงรหัสถัดไปคือข้อความของตัวชี้วัดนั้น
5. เซลล์ที่ไม่มีรหัสแต่มีข้อความ ถือเป็นข้อความต่อเนื่องของตัวชี้วัดก่อนหน้าในคอลัมน์เดียวกัน (เกิดจากการตัดบรรทัดข้ามแถวในต้นฉบับ)
6. เซลล์ผสานแนวตั้งที่ข้อความซ้ำกับแถวก่อนหน้าจะถูกข้าม และรหัสที่เคยพบแล้วจะไม่สร้างซ้ำ
7. เมื่ออ่านจบ เทียบจำนวนกับตารางสรุปและบันทึกผลในชีต validation

## 6. ข้อจำกัดที่ควรทราบ

ต้นฉบับบางตารางมีการผสานเซลล์และตัดบรรทัดไม่สม่ำเสมอ อาจทำให้ข้อความตัวชี้วัดบางรายการขาดหรือเกิน หรือระบุกลุ่มที่คลาดเคลื่อน จึงควรตรวจทานรายการที่ชีต validation แสดงสถานะ ต้องตรวจสอบ เทียบกับไฟล์ PDF ต้นฉบับ แก้ไขในชีต แล้วทำเครื่องหมาย reviewed เป็น TRUE เพื่อป้องกันการถูกทับในการนำเข้าครั้งต่อไป
