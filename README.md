# ฐานข้อมูลตัวชี้วัดระหว่างทางและตัวชี้วัดปลายทาง

ฐานข้อมูลและหน้าเว็บค้นหาตัวชี้วัดระหว่างทางและตัวชี้วัดปลายทาง ตามหลักสูตรแกนกลางการศึกษาขั้นพื้นฐาน พุทธศักราช ๒๕๕๑ ครอบคลุม 8 กลุ่มสาระการเรียนรู้ ชั้น ป.1 ถึง ม.3 จัดทำเพื่อสนับสนุนการกำหนดโครงสร้างรายวิชา การออกแบบหน่วยการเรียนรู้ และการวัดและประเมินผล ตามแนวทางของ สพฐ. ที่แยกการประเมินเพื่อพัฒนา (ตัวชี้วัดระหว่างทาง) ออกจากการประเมินเพื่อตัดสินผล (ตัวชี้วัดปลายทาง)

## สถาปัตยกรรมระบบ

```
Google Drive (ไฟล์ .docx ต้นฉบับ 8 กลุ่มสาระ)
      │  Apps Script แปลงเอกสารและแยกตัวชี้วัด
      ▼
Google Sheet (ฐานข้อมูลหลัก แก้ไขและตรวจทานได้)
      │  Apps Script Web App ให้บริการข้อมูลแบบ JSON
      ├──────────────► หน้าเว็บค้นหาบน GitHub Pages (อ่านข้อมูลสด)
      │
      └─ GitHub Actions ดึงข้อมูลรายสัปดาห์ เก็บเป็น data/*.json และ data/csv/*.csv
         (สำเนาสำรอง มีประวัติการแก้ไข และเป็นแหล่งข้อมูลสำรองของหน้าเว็บ)
```

Google Sheet เป็นแหล่งข้อมูลหลักเพียงแห่งเดียว การแก้ไขทำที่ชีต ส่วน GitHub ทำหน้าที่เผยแพร่และเก็บประวัติ

## โครงสร้างไฟล์

```
kss-indicators-db/
├── index.html                  หน้าเว็บค้นหา (GitHub Pages)
├── config.js                   ตั้งค่า URL ของ API
├── apps-script/
│   ├── Parser.gs               ตัวแยกข้อมูลจากตาราง (ทดสอบได้ด้วย Node.js)
│   ├── Code.gs                 เมนู การนำเข้า การตรวจสอบ และ Web API
│   └── appsscript.json         ค่าตั้งโปรเจกต์และบริการ Drive API
├── data/
│   ├── indicators.json         ข้อมูลทั้งหมด (ปัจจุบันเป็นข้อมูลตัวอย่าง)
│   └── csv/                    ไฟล์ CSV รายตาราง สร้างโดย GitHub Actions
├── scripts/sync-from-sheet.mjs ดึงข้อมูลจาก API มาเป็นไฟล์
├── tests/parser.test.js        ชุดทดสอบตัวแยกข้อมูล
├── docs/data-structure.md      รายละเอียดโครงสร้างข้อมูล
└── .github/workflows/sync-sheet.yml
```

## ขั้นตอนติดตั้ง

### ส่วนที่ 1 สร้างฐานข้อมูลใน Google Sheet

1. สร้าง Google Sheet ใหม่ ตั้งชื่อ เช่น ฐานข้อมูลตัวชี้วัด
2. เปิดเมนู ส่วนขยาย แล้วเลือก Apps Script
3. สร้างไฟล์ Parser.gs และ Code.gs แล้วคัดลอกเนื้อหาจากโฟลเดอร์ apps-script
4. ที่ ค่าโปรเจกต์ เปิด แสดงไฟล์ appsscript.json แล้วคัดลอกเนื้อหาจากไฟล์ในคลังนี้ (หรือเพิ่มบริการ Drive API v3 จากเมนู บริการ)
5. ตรวจสอบ CONFIG.SOURCE_FOLDER_ID ใน Code.gs ให้ตรงกับโฟลเดอร์ต้นฉบับ บัญชีที่รันต้องมีสิทธิ์อ่านโฟลเดอร์นั้น
6. บันทึก กลับไปที่ชีต รีเฟรชหน้า จะพบเมนู ฐานข้อมูลตัวชี้วัด
7. เลือก 1. สร้างชีตและหัวตาราง แล้วเลือก 2. นำเข้าตัวชี้วัดจาก Google Drive และอนุญาตสิทธิ์ตามที่ระบบขอ
8. หากระบบแจ้งว่าหมดเวลารอบนี้ ให้เรียกนำเข้าซ้ำ ระบบจะทำต่อจากไฟล์ที่ค้างไว้

### ส่วนที่ 2 ตรวจทานข้อมูล

1. เปิดชีต validation รายการที่มีสถานะ ต้องตรวจสอบ คือชั้นที่จำนวนตัวชี้วัดไม่ตรงกับตารางสรุปของเอกสาร
2. กรองชีต indicators ตามกลุ่มสาระและชั้นนั้น เทียบกับไฟล์ PDF ต้นฉบับ แล้วแก้ไข
3. ใส่ TRUE ในคอลัมน์ reviewed ของแถวที่ตรวจแล้ว แถวเหล่านี้จะไม่ถูกทับเมื่อนำเข้าใหม่
4. เลือกเมนู 3. สร้างรายงานตรวจสอบจำนวน เพื่อคำนวณผลใหม่

### ส่วนที่ 3 เปิดบริการข้อมูล (Web API)

1. ใน Apps Script เลือก การทำให้ใช้งานได้ แล้วเลือก การทำให้ใช้งานได้รายการใหม่ ประเภท เว็บแอป
2. เรียกใช้ในฐานะ ฉัน และผู้มีสิทธิ์เข้าถึง ทุกคน
3. คัดลอก URL ที่ลงท้ายด้วย /exec

รูปแบบการเรียกใช้

| คำขอ | ผลลัพธ์ |
| --- | --- |
| ?action=all | ข้อมูลทุกตาราง |
| ?action=indicators&subject=ค&grade=ป.4&type=ปลายทาง | ตัวชี้วัดตามเงื่อนไข |
| ?action=indicators&q=เศษส่วน | ค้นหาข้อความหรือรหัส |
| ?action=standards, strands, subjects, summary, validation | ข้อมูลรายตาราง |

### ส่วนที่ 4 เผยแพร่บน GitHub

1. สร้างคลังใหม่บน GitHub แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้
2. แก้ config.js ใส่ URL จากส่วนที่ 3 ในค่า API_URL
3. ที่ Settings เลือก Pages กำหนด Source เป็น Deploy from a branch สาขา main โฟลเดอร์ root
4. ที่ Settings เลือก Secrets and variables แล้ว Actions แท็บ Variables เพิ่มตัวแปร SHEET_API_URL เป็น URL เดียวกัน
5. ที่แท็บ Actions เรียก ซิงก์ข้อมูลตัวชี้วัดจาก Google Sheet ด้วยตนเองหนึ่งครั้ง ต่อจากนั้นระบบจะทำงานทุกสัปดาห์

## ความสามารถของหน้าเว็บ

1. ค้นหาด้วยรหัสหรือข้อความ รองรับทั้งเลขไทยและเลขอารบิก
2. กรองตามกลุ่มสาระ ชั้น มาตรฐาน และประเภทตัวชี้วัด
3. จัดกลุ่มการแสดงผลตามชั้นและมาตรฐาน หรือตามกลุ่มตัวชี้วัด เพื่อเห็นเส้นทางจากตัวชี้วัดระหว่างทางสู่ตัวชี้วัดปลายทาง
4. เลือกตัวชี้วัดเก็บเป็นรายการ ใช้เป็นร่างโครงสร้างรายวิชาหรือหน่วยการเรียนรู้ ส่งออกเป็น CSV ที่เปิดใน Excel และ Google Sheets ได้โดยภาษาไทยไม่เพี้ยน หรือคัดลอกเป็นข้อความ

## การทดสอบ

```
node tests/parser.test.js
```

ชุดทดสอบใช้แถวจริงจากเอกสารกลุ่มสาระคณิตศาสตร์ ครอบคลุมกรณีเซลล์ผสาน ข้อความตัดข้ามแถว และหลายรหัสในเซลล์เดียว

## แหล่งข้อมูล

เอกสารตัวชี้วัดระหว่างทางและตัวชี้วัดปลายทาง และแนวทางการวัดและประเมินผลการเรียนรู้ของสำนักงานคณะกรรมการการศึกษาขั้นพื้นฐาน
